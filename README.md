# Chirp

A Kotlin Multiplatform (KMP) application targeting Android, iOS, and Desktop (JVM) using Compose Multiplatform. The project is organized as a multi-module repository with shared core/feature modules and a Compose-driven UI.

This README documents the stack, requirements, setup, run/test commands, available scripts, environment variables, project structure, and licensing notes. Unknowns are explicitly marked as TODO to avoid guessing.

## Overview
- Platforms: Android, iOS, Desktop (JVM)
- UI: JetBrains Compose Multiplatform (Material 3, Adaptive libs)
- Language: Kotlin (KMP)
- Build: Gradle Wrapper with Kotlin DSL (AGP + KMP)
- DI: Koin (via BOM and compose integration)
- Networking: Ktor client (core, logging, auth, content-negotiation, JSON)
- Persistence: Room (Android), AndroidX DataStore, SQLite bundled
- Coroutines/DateTime: kotlinx-coroutines, kotlinx-datetime
- Images: Coil 3
- Permissions (KMP): moko-permissions

Key coordinates (from gradle/libs.versions.toml):
- Kotlin 2.2.0
- Compose Multiplatform 1.9.0-beta01, Compose BOM 2025.07.00
- Android Gradle Plugin 8.11.1
- Min SDK 26, Target/Compile SDK 36

## Requirements
- JDK 11 (project sets Java 11 toolchain/JVM target)
- Gradle Wrapper (included): use ./gradlew on macOS/Linux, .\gradlew.bat on Windows
- Android Studio (latest stable) with Android SDK platforms and build tools for API 36
- Xcode (for iOS build/run)
- Kotlin/Compose Multiplatform tooling (bundled via Gradle plugins)

Optional tooling:
- A physical or virtual Android device for instrumented tests
- A macOS machine with Xcode/iOS Simulator for iOS

## Setup
1. Clone the repository.
2. Open the project in Android Studio (recommended) or IntelliJ IDEA with KMP support.
3. Let Gradle sync and download dependencies.
4. Configure local Android SDK via local.properties if needed (auto-generated by Android Studio).
5. iOS: Open iosApp/iosApp.xcodeproj in Xcode for running on iOS Simulator or device.

## Run/Build
The main entry module for running apps is composeApp.

Android (assemble debug APK):
- macOS/Linux: ./gradlew :composeApp:assembleDebug
- Windows: .\gradlew.bat :composeApp:assembleDebug

Desktop (JVM) run:
- macOS/Linux: ./gradlew :composeApp:run
- Windows: .\gradlew.bat :composeApp:run

iOS:
- Open iosApp in Xcode and run the iOS target.
- KMP frameworks are produced from composeApp iOS targets; Xcode uses the iOS app wrapper in iosApp.

Release/distributions (Desktop):
- macOS/Linux: ./gradlew :composeApp:packageDistributionForCurrentOS
- Windows: .\gradlew.bat :composeApp:packageDistributionForCurrentOS

Clean/build all:
- ./gradlew clean build (or .\gradlew.bat clean build on Windows)

## Scripts and Gradle tasks
Common tasks you may find useful:
- :composeApp:assembleDebug – Android debug APK
- :composeApp:assembleRelease – Android release APK (signing configuration not provided here)
- :composeApp:run – Run desktop target
- :composeApp:build – Build all composeApp targets
- :clean, :build – Root tasks for cleaning and building the whole multi-module project

Module-specific tasks (examples):
- :core:<module>:test – Run JVM/common tests for core modules

## Tests
This project includes common tests and Android host/device tests in several modules.

Run all tests:
- macOS/Linux: ./gradlew test
- Windows: .\gradlew.bat test

Run tests for a specific module (examples):
- ./gradlew :core:domain:test
- ./gradlew :feature:chat:data:test

Android instrumented/device tests (if configured for a module):
- ./gradlew :<module>:connectedAndroidTest

Note: Some modules have androidHostTest/androidDeviceTest source sets. Availability of instrumented tests depends on module configuration and connected device/emulator.

## Project structure
High-level modules (from settings.gradle.kts):
- composeApp – KMP application module (Android, iOS frameworks, Desktop). Desktop main class: dev.gaddal.chirp.MainKt
- core
  - core:presentation
  - core:domain
  - core:data
  - core:designsystem
- feature:auth
  - feature:auth:presentation
  - feature:auth:domain
- feature:chat
  - feature:chat:presentation
  - feature:chat:domain
  - feature:chat:data
  - feature:chat:database
- iosApp – Xcode project for running the iOS app shell

Notable source locations:
- composeApp/src/commonMain/kotlin – Shared UI and logic for all platforms
- composeApp/src/androidMain – Android-specific sources and AndroidManifest.xml
- composeApp/src/jvmMain – Desktop entry point (dev.gaddal.chirp.MainKt)
- composeApp/src/iosMain – iOS-specific Kotlin code/framework config
- iosApp/ – SwiftUI wrapper and app entry for iOS
